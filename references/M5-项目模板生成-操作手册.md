# M5 项目模板生成 操作手册

> 版本：**v3.0（2026-10-10，V5 重构：企业模板废弃，通用格式配置取代）**
> 依据：用户 2026-10-10 重新设计——"双模板控制过于复杂且不通用……实际可以使用一个格式配置文件把格式要求设定好，这样就和内容无关，项目模板深拷贝招标文件中的投标文件（采购文件）格式中的内容（含表格），一字都不能差一个内容都不能丢。然后根据格式文件来生成项目模板（带文字占位和图片占位），在生成项目模板前可以根据解析的招标文件来校验一下格式配置文件看没有冲突和需要补充的内容（agent 来校验）。"
> 配套：`references/M5-通用格式配置-说明.md`（格式体系/图片位置/独占一面/收敛规则）、`references/M5-格式配置校验-提示词.md`（生成前 agent 校验）、`references/M5-项目模板检查-提示词.md`（生成后 agent 检查）、`scripts/m5_project/format_config.json`（机读配置）。

## 0. 确定性原则（最高优先级，违反即事故）

- 商务标制作建立在**确定性**基础上，AI 只是辅助，**整个过程必须用代码控制保证正确性**。
- **每个步骤都必须人工确认**：素材清单、招标文件解析结果、格式配置校验结果、项目模板生成结果、agent 检查报告。
- **通用格式配置 = V5 格式唯一来源**（企业模板已废弃）：字体/字号/行距/缩进/对齐/表格/页面/图片图框占位/图片插入位置/独占一面/收敛顺序全部由 `format_config.json` 定义；未经授权不得擅自修改，配置变更须人工确认。
- **未经授权不使用 agent**：仅允许 ①M4 招标解析通道B（固化提示词）、②M5 生成前格式配置校验（固化提示词）、③M5 生成后项目模板检查（固化提示词）三处；agent 结果必须人工确认。

## 1. 项目模板三依据（V5）

| 依据 | 来源 | 作用 |
| --- | --- | --- |
| **内容契约** | 招标文件「投标文件格式」**深度拷贝**（一字不改、一个内容不丢；仅「第X章 投标文件格式」章节标题不拷贝） | 项目模板的**文字与表格内容** |
| **格式契约** | **通用格式配置 `format_config.json`**（与内容无关，一套配置适用所有项目；企业模板废弃） | 项目模板的**格式与排版**：字体（全仿宋体系）/字号/行距固定28磅/首行缩进2字符/对齐/表格表头加粗底纹/页面 A4 边距/**图片图框占位（image_spec 尺寸 + 图片插入位置表 + 数量按素材清单动态）**/**独占一面清单**/收敛顺序 |
| **素材清单** | 用户确认的 v5.1 素材清单（`proj-mat` 组装） | 文字占位【】与图片占位【图片：xxx】的**将来填充源** |

**项目模板生成 = 内容契约（招标原文深拷贝） + 格式契约（通用格式配置） + 素材清单（占位填充源）**

## 2. 前置条件（M4 完成，三个闸门全部通过）

| # | 闸门 | 通过条件 |
| --- | --- | --- |
| 1 | 招标解析确认 | 投标要点经用户确认（双通道解析 + HTML 展示 + 差异裁决） |
| 2 | 素材清单确认 | 用户确认素材清单（`proj-mat` 组装后人工核对） |
| 3 | 素材缺口收口 | 文字性→会话输入、图片/文件→继续上传、用户豁免；`tender-gap --verify` 通过（`proj-gen` 带机器闸门，未收口拒绝生成） |

## 3. 项目模板生成流程（六步，V5）

### ① 内容契约生成（确定性脚本，A1）
- 命令：`proj-content-contract --project <项目名> [--source <招标文件.docx>]`
- 产出：`招标解析/内容契约/内容契约.json`（格式文件清单：id/标题/块范围）
- 说明：块范围定位「投标文件格式」章节内的段落/表格；文字更新源=招标原文。

### ② 格式配置校验（生成前 agent 校验，A1 生成指令 + agent 执行 + 人工确认）
- 命令：`proj-config-check --project <项目名> [--format-config <format_config.json>]`
- 产出：`招标解析/格式配置校验指令.json`（固化提示词 + 三份输入路径 + 输出 schema）
- 说明：agent 读取指令执行**只读校验**——对照内容契约/招标原文检查格式配置 8 项（文件类型覆盖/字体体系/图片插入位置/独占一面/页面参数/行距缩进/图片尺寸/占位规则），报告 `招标解析/检查报告_格式配置.json`；
- **闸门**：结果必须**人工确认**；确认通过前不得执行 `proj-gen`；配置有缺失（待补充）→ 人工补充格式配置后重校验。

### ③ 生成（确定性脚本，A1 执行 + 结果人工确认）
- 命令：`proj-gen --project <项目名> [--format-config <format_config.json>]`
- 产出：`项目级/<项目>/项目模板/`（各文件 docx + 生成记录.json + 项目占位符清单.md + 页数校验.json）
- 生成逻辑（V5）：
  1. **内容**：招标原文投标文件格式**深度拷贝**（段落/表格一字不改、一个内容不丢；章节标题段跳过；原文示例图/格式设置清除，只留文字表格）；
  2. **格式**：按通用格式配置应用（`format_applier`）——仿宋体系（正文12/小节标题14/章标题22/一级标题16/封面22-26）、行距固定28磅、首行缩进2字符、对齐、表格表头加粗底纹 D9D9D9、页面 A4 边距、页脚页码（封面无）；
  3. **图片占位**：图框占位（`ph_preview` 灰底框）——位置=「图片插入位置」表锚点（标题段/附：标注段/表格后），大小=image_spec 素材尺寸，数量=素材清单动态（业绩图片数=该业绩图片素材数、人员图片数=该人员证书/职称/身份证/社保素材数）；只放图框**无实际内容**；
  4. **独占一面**：格式配置「独占一面」清单（文件级首分页符 + 资格证明表内附表1/附表3/附表8 标题前分页符）；
  5. **硬校验**：代码文字逐字比对（`verify_text`）+ 页数校验/独占面排版收敛（`page_fit`，收敛顺序=删空行→行距28→24→…→10.5→表格行高→内边距→删分页符；禁改字号/页边距）。

### ④ 检查（代码硬校验 + agent 检查，结果人工确认）
- 命令：`proj-check --project <项目名>`
- 产出：`项目模板/检查指令.json`（固化提示词 + 硬校验结果 + 输出 schema）
- 说明：agent 读取指令执行**只读检查**（8 项固定清单），报告 `项目模板/检查报告.json`；**结果人工确认**，确认通过才可冻结。

### ⑤ 人工修改 → 冻结（用户拍板，C8/D11）
- 命令：`proj-freeze --project <项目名> [--check]`
- 说明：用户可修改/增加项目模板（改占位、加内容）；冻结=登记 fb 基线 + 只读版本；**商务标只认冻结版**（改动被 fb audit 检出）。

### ⑥ 商务标生成（填充，唯一模板来源）
- 商务标 = **重新全面读取项目模板**（唯一模板来源）+ 招标解析 + 素材清单填充（`proj-fill`）。
- 占位填充内容来自招标解析与素材清单，**不是任何内置内容**。

## 4. 决策权限表引用（固化提示词 v1.6）

| 权限 | 事项 |
| --- | --- |
| A1 确定性脚本 | 内容契约生成、格式配置校验指令生成、项目模板生成、代码硬校验、页数校验 |
| agent（固化提示词） | 格式配置校验（生成前）、项目模板检查（生成后）——结果人工确认 |
| C 用户拍板 | 素材清单确认（C4）、格式配置确认/修改（C6）、agent 校验/检查报告确认、冻结（C8）、删除覆盖（C10） |

## 5. 命令速查

```
proj-content-contract --project <项目名>              # ① 内容契约生成
proj-config-check --project <项目名>                  # ② 格式配置校验指令（agent 执行，人工确认）
proj-gen --project <项目名> [--format-config F]       # ③ 生成项目模板（深拷贝+格式配置+硬校验）
proj-check --project <项目名>                         # ④ 项目模板检查指令（agent 执行，人工确认）
proj-freeze --project <项目名> [--check]              # ⑤ 冻结（商务标唯一来源）
proj-fill --project <项目名>                          # ⑥ 商务标填充
```

## 6. 常见情形

- **企业模板相关命令已废弃**：`proj-tpl-select`/`proj-tpl-import`/`proj-diff` 已移除；企业模板资产已清除（企业级/模板库仅保留「素材清单空白表」）。
- **格式配置不适用本项目**：配置校验（②）agent 报「待补充」→ 人工补充配置条目（新增文件类型/图片位置/独占项）→ 重新校验确认。
- **图片占位**：只放图框（灰底框+尺寸标注+待补素材），数量按素材清单动态；用户可修改/增加图框；具体内容商务标生成时填充。
- **独占一面**：封面/开标一览表/投标函正文/投标函附录/法代/授权/中小企业声明函/承诺书/附表1 组织机构/每份附表8 简历表/每份附表3 业绩表——项目模板必须独占一面，严禁跨页；收敛顺序按配置（删空行→行距→表格→内边距→删分页符），不得改字号/页边距；仍跨页报待人工/agent 复核。
