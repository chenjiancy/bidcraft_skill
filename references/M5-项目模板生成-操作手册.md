## 0. 确定性原则（最高优先级，违反即事故）

- 商务标制作建立在**确定性**基础上，AI 只是辅助，**整个过程必须用代码控制保证正确性**。
- **每个步骤都必须人工确认**：素材清单、母版制作结果、试生成结果、agent 检查报告。
- **v2.0 布局样板范式（2026-10-19 定案，取代 V5）**：**企业模板=布局样板母版**（人工制作：固定条款原样照抄、
  可变文字 `{{ }}`、图片 `【图片占位：类别】`、人员/业绩只做样板行/页，**禁止硬编码人名/证书名**）；
  **项目模板=母版复制**；**商务标=fill-tpl 填充**（占位索引→样板复制→类别聚合依序消费→未列不生成/缺图披露，素材清单驱动）。
- **V5 已作废**：format_config.json 格式唯一来源、招标原文深拷贝、CELL_MAP 坐标+人名硬编码全部退役。
- **未经授权不使用 agent**：仅允许 ①M4 招标解析通道B（固化提示词）、②M5 生成后商务标检查（固化提示词）两处；agent 结果必须人工确认。

## 3. 商务标生成流程（v2.0，fill-tpl 四步引擎）

### ① 占位索引扫描（确定性脚本）
- 扫描母版全文（正文段 + 文本框段 + 表格内段），输出该件母版的**占位索引**：
  - 文字键清单：`{{ }}` 分通用键（直填）/ 行级键（`{{ 人员姓名 }}` 等=样板行定位）；
  - 图片类别序列：`【图片占位：类别】` 按出现顺序记录（类别 + 段落/表格/文本框定位）；
  - 样板定位：含行级键的行=样板行；含 `{{ 人员姓名 }}` 的简历表及其后证书图框段=简历样板组（人员锚点法，见 `fill-tpl-v2-refactor.md` 3.2.1）。

### ② 样板复制（确定性脚本，核心引擎）
- 按素材清单数量深拷贝 XML 节点（保留格式/合并单元格/文本框）：人员配备表行、简历样板组、业绩汇总行、业绩明细页。
- 清单数 > 样板数 → 复制补齐；清单数 < 样板数 → 删除多余样板；复制后行级键按对应素材对象填值。

### ③ 类别聚合填充（确定性脚本）
- 图片按**类别**从素材清单聚合路径列表，按模板中占位出现顺序**依序消费**：
  | 占位类别 | 聚合来源 |
  |---|---|
  | 总监注册监理工程师证书 | 总监的「注册证书」（**总监识别=职务字段含「总监」/「总监理工程师」，personnel[0] 仅兜底**） |
  | 高级工程师职称证书 | 总监「职称证书」中高级职称部分 |
  | 职称证书 / 岗位证书 | 非总监人员职称证书展平 / 岗位证书展平（按 personnel 顺序） |
  | 身份证 / 社保证明 | 全部人员身份证展平 / social_security_required.paths |
  | 企业资质证书 / 企业法人营业执照 / 开户许可证 | qualification_required 按名称匹配 |
  | 三体系认证证书 | iso_certificates |
  | 先进监理企业证书 / 监理示范工程 / 优秀总监证书 | honors 按名称关键词匹配 |
  | 业绩材料 | performance.paths 展平 |
- **专业监理工程师 / 监理员不参与图片类别识别**：职务是数据，直接填入 `{{ 人员职务 }}`；**某人无某类证书 → 该类自动少一张**。
- **简历样板组内图片按该人员对象取数，组间不串**（不参与全局依序消费）。
- 图片按文本框/图框尺寸等比缩放（image_spec v2.0）插入，删占位文案；fill 保持母版版面不重排。

### ④ 未列不生成 + 缺图披露（确定性脚本）
- 素材清单未列的类别/数量 → 对应样板不复制、图框不填充（删框或留待缺图披露），**不得用模板内固化内容硬生成**。
- 某类别素材数不足占位数 → 填充结果标注缺图（类别 + 缺 N 张），不静默。
- 固定素材豁免（`_商务标固定素材.json` 声明的组织机构框图/企业简介等）不受驱动约束。

### ⑤ 检查（代码硬校验 + agent 检查，结果人工确认）
- `fill-tpl --check`：占位符清零、素材文件存在性、页数一致性、冻结版一致（复用 M7 checker 规则）。
- agent 检查：必须遵循 `references/M5-项目模板检查-提示词.md`（v2.0），只读不改、结果人工确认。

## 6. 常见情形

- **母版无某类别占位**：素材清单有该类素材但母版没排版 → 缺图披露 + 提示补母版版面（不自动插入）。
- **母版占位多余**：清单素材数 < 模板占位数 → 按实际数量消费，多余图框删框+缺图披露。
- **人员缺证书**：某人无某类证书 → 该类自动少一张，其余人员按 personnel 顺序照常消费，不串位。
- **独占一面**：以母版排版为准（已完标书实际分页归纳进母版）；fill 不重排，保持母版版面。
