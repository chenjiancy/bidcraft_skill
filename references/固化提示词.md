## v1.3（2026-10-10）

### 0. 商务标制作确定性原则（用户明示，最高优先级，2026-10-10 完整复述确认）

> 来源：2026-10-10 用户会话——"商务标制作是建立在确定性基础，ai只是辅助，不得未经用户确认随意作主，这是灾难性的"；"我没有让你使用agent的地方，你不能擅自使用，自行做主，我的商务标制作是需要高可靠性的"；"整个过程都必须使用代码来控制保证完全正确性，且代码可以实现正确性"。

1. **商务标制作 = 高可靠性系统工程，整个过程必须使用代码（确定性脚本）控制**，保证完全正确性——**代码可以实现正确性**；AI/agent 不是执行主体，不得在未授权环节介入做主。
2. **AI/agent 仅在用户明确授权的环节使用**，且**由提示词控制、结果必须人工确认**：
   - **招标文件解析**：双通道解析（通道 A=代码/机器解析；通道 B=agent 解析，有提示词控制），解析结果人工确认；
   - **标书检查、模拟评标等后续环节**：同样使用双通道，同样由提示词控制。
   - 除上述授权环节外，**不得擅自使用 agent，不得自行做主**。
3. **商务标制作每个步骤都必须人工确认**：素材清单（确认后才能进入下一步）、格式配置（用户确认/修改）、格式配置校验结果（agent 校验报告确认）、项目模板生成（用户审核确认）、招标文件解析结果（双通道产出人工确认）——「AI 产出/代码产出 → 人工确认闸门 → 进入下一环节」。
4. **临时授权不改变以上原则**：授权只豁免"等待确认的动作节奏"，不豁免"用户拍板项由用户拍板"；发现方向性问题立即停下报告。
5. **规则未被执行 = 系统运行在不可靠基础上，完全不正确**——此为最高优先级检查项，任何流程/代码偏离立即纠正。

## v1.4（2026-10-10）

### 2.1 模板选择·代理机构非硬性规则（用户明示，2026-10-10）

> 来源：用户 2026-10-10——"③ 模板选择,你查询的流程是对的，但是如果没有找到对应的招标代理机构，人工可能选择确定使用哪个模板（需要使用哪个代理机构的企业模板不是硬性规定，用户也可以组合不同代理机构的企业模板生成你需要使用的企业模板），本验证项目使用大成代理的模板"。

- 检索/查询流程不变：按代理机构 + 采购方式查询企业模板库候选 → 列示候选与贴近度（B6）。
- **未找到对应招标代理机构** → 用户可**指定**使用任意代理机构的企业模板（`--agency` / `--base-dir`）；**不是硬性规定**。
- 用户可**组合不同代理机构的企业模板**生成所需模板基底（`--base-dir` 分号分隔多目录；`--map '文件=模板文件'` 指定个别文件）。
- 最终选用由用户拍板（C6）；系统无此类模板 → 用户制作对应模板入库。
- 验证项目（和县2026）指定用**大成工程咨询**代理模板做基底。

### 2.2 M5 商务标生成规则（v2.0 重写：布局样板范式——企业模板=版面样板，素材清单=数据，V5 作废）

> 来源：用户 2026-10-19 定案——"模板=版面样板（只描述每类素材如何排版），素材清单=数据（决定放哪些人/证书/多少/顺序）；素材清单未列出的素材商务标不生成；模板内禁止硬编码人名/证书名"。V5（format_config.json 格式唯一来源、招标原文深拷贝、CELL_MAP 坐标+人名硬编码）全部作废。

- **① 企业模板（布局样板母版）**：人工按已完标书制作，**只描述每类素材如何排版**——固定条款原样照抄、可变文字 `{{ 键名 }}`、图片 `【图片占位：类别】`（图框内类别占位文案，框尺寸=图片布局尺寸，**禁人名/证书名**）；人员/业绩只做样板行/样板页（含 `{{ 人员姓名 }}` 锚点段 + 简历表 + 其后到分页符前的图框段归该人）；哪些页独占一面以已完标书实际排版为准。
- **② 项目模板** = 企业母版深拷贝（fill-tpl 第一步），**不新增内容、不改版面**。
- **③ 素材清单（数据）**：personnel（总监=职务含「总监」/「总监理工程师」，personnel[0] 仅兜底；专业监理工程师/监理员为数据 `{{ 人员职务 }}` 直填）、performance、qualification_required、honors、iso_certificates、social_security_required 等；**清单未列出的素材商务标不生成**。
- **④ fill-tpl 四步引擎（唯一商务标生成管线）**：①占位索引（通用键/行级键/图片类别/样板行/整表样板，简历组内图框排除全局）→ ②样板复制（人员配备/业绩汇总行、简历/业绩整组按素材数量深拷贝，保留格式/合并单元格）→ ③类别聚合填充（图片按类别依序消费，简历组内按人员对象取数、组间不串）→ ④未列不生成 + 缺图披露（删框 + 缺图清单.md）。
- **⑤ 检查（M5-项目模板检查-提示词.md v3.0）**：检查对象=fill-tpl 填充后的商务标，依据=母版版面 + 素材清单（版面保持/文字键填充/图片类别填充/未列不生成/缺图披露），结果人工确认。
- **⑥ 商务标交付**：商务标 = 母版版面（项目模板）+ 素材清单数据；任何人/证书/业绩的数量与顺序只由素材清单决定。
