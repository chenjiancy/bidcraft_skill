## v1.0（2026-10-10）

### 1. M5 项目模板生成规则（用户明示，纠正此前实现偏差）

- **格式契约 = 企业模板库中的模板文件**（格式与排版契约、项目模板的基底）：查询并解析招标文件中格式**最贴近**的模板文件 → **选择后报告用户确认**；用户认为不正确可**指定选用哪个模板**；系统中无此类模板 → **用户制作对应模板入库**。
- **内容契约 = 招标文件解析出的投标文件格式**（响应文件格式独立文件，内容地基）：项目模板中**占位或企业模板已有内容除外**，其余内容根据内容契约更新。
- 文字 100% 契约 + 内容校验差异由用户决定（铁律 D25）——见 `references/M2-模板库-需求对齐.md` v1.4。
- 来源：2026-10-10 用户会话明示（"格式契约要来自于企业模板中的模板文件……招标文件解析出来的投标文件格式是内容契约……"）。

### 2. 决策权限表（三级；条目待用户逐条确认，默认 C 级）

| 级别 | 含义 | 处理方式 |
|------|------|----------|
| A 自主 | 用户明确授权可自行决定 | 直接执行，完成后汇报 |
| B 报告后执行 | 执行前须向用户报告方案 | 先报告，用户无异议再执行 |
| C 用户拍板 | 用户决策后才能执行 | 停下等待用户决定，不自作主张 |

- **未列入权限表的决策点一律按 C 级（用户拍板）处理**。
- 以下候选条目（依据历史已确认规则归纳）**待用户确认后升版本入表，确认前一律按 C 级处理**：

|--------|--------|--------------------|
