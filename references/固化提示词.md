## v1.3（2026-10-10）

### 0. 商务标制作确定性原则（用户明示，最高优先级，2026-10-10 完整复述确认）

> 来源：2026-10-10 用户会话——"商务标制作是建立在确定性基础，ai只是辅助，不得未经用户确认随意作主，这是灾难性的"；"我没有让你使用agent的地方，你不能擅自使用，自行做主，我的商务标制作是需要高可靠性的"；"整个过程都必须使用代码来控制保证完全正确性，且代码可以实现正确性"。

1. **商务标制作 = 高可靠性系统工程，整个过程必须使用代码（确定性脚本）控制**，保证完全正确性——**代码可以实现正确性**；AI/agent 不是执行主体，不得在未授权环节介入做主。
2. **AI/agent 仅在用户明确授权的环节使用**，且**由提示词控制、结果必须人工确认**：
   - **招标文件解析**：双通道解析（通道 A=代码/机器解析；通道 B=agent 解析，有提示词控制），解析结果人工确认；
   - **标书检查、模拟评标等后续环节**：同样使用双通道，同样由提示词控制。
   - 除上述授权环节外，**不得擅自使用 agent，不得自行做主**。
3. **商务标制作每个步骤都必须人工确认**：素材清单（确认后才能进入下一步）、格式配置（用户确认/修改）、格式配置校验结果（agent 校验报告确认）、项目模板生成（用户审核确认）、招标文件解析结果（双通道产出人工确认）——「AI 产出/代码产出 → 人工确认闸门 → 进入下一环节」。
4. **临时授权不改变以上原则**：授权只豁免"等待确认的动作节奏"，不豁免"用户拍板项由用户拍板"；发现方向性问题立即停下报告。
5. **规则未被执行 = 系统运行在不可靠基础上，完全不正确**——此为最高优先级检查项，任何流程/代码偏离立即纠正。

## v1.4（2026-10-10）

### 2.1 模板选择·代理机构非硬性规则（用户明示，2026-10-10）

> 来源：用户 2026-10-10——"③ 模板选择,你查询的流程是对的，但是如果没有找到对应的招标代理机构，人工可能选择确定使用哪个模板（需要使用哪个代理机构的企业模板不是硬性规定，用户也可以组合不同代理机构的企业模板生成你需要使用的企业模板），本验证项目使用大成代理的模板"。

- 检索/查询流程不变：按代理机构 + 采购方式查询企业模板库候选 → 列示候选与贴近度（B6）。
- **未找到对应招标代理机构** → 用户可**指定**使用任意代理机构的企业模板（`--agency` / `--base-dir`）；**不是硬性规定**。
- 用户可**组合不同代理机构的企业模板**生成所需模板基底（`--base-dir` 分号分隔多目录；`--map '文件=模板文件'` 指定个别文件）。
- 最终选用由用户拍板（C6）；系统无此类模板 → 用户制作对应模板入库。
- 验证项目（和县2026）指定用**大成工程咨询**代理模板做基底。

### 2.2 M5 项目模板生成规则（v1.6 重写：V5 通用格式配置方案，企业模板废弃）

> 来源：用户 2026-10-10——"这种双模板控制来生成商务标的逻辑过于复杂且不利于自动化商务标生成，因为需要根据不同的招标文件事先制作好企业模板这个工作量太大且不具有通用性。实际可以使用一个格式配置文件把格式要求设定好，这样就和内容无关，项目模板深拷贝招标文件中的投标文件（采购文件）格式中的内容（含表格），一字都不能差一个内容都不能丢。然后根据格式文件来生成项目模板（带文字占位和图片占位），在生成项目模板前可以根据解析的招标文件来校验一下格式配置文件看没有冲突和需要补充的内容（agent来校验）。"；"图片占位使用图框来占位表达了图片的大小，素材、位置。前面对不同素材的大小做的规定要保留"。

- **① 内容契约（文字/表格）= 招标文件「投标文件格式」章节深度拷贝**：仅「第X章 投标文件格式」章节标题不拷贝，其后所有投标格式内容（含表格）全部保留；**不得更改一个字、不得丢一个内容**（含空格/标点/换行）；原文示例图与无关格式设置清除，具体格式按格式配置设置。
- **② 格式契约（格式）= 通用格式配置 `format_config.json`（V5，企业模板废弃）**：字体（全仿宋体系：正文12/小节标题14/章标题22/一级标题16/封面22-26，无黑体）、行距固定28磅、首行缩进2字符、对齐、表格表头加粗底纹 D9D9D9、页面 A4 边距、页脚页码（封面无）；**图片图框占位**（图框表达大小/素材/位置，大小=image_spec 素材尺寸规定，位置=图片插入位置表锚点，数量=素材清单动态）；**独占一面清单**（文件级：封面/开标一览表/投标函正文/投标函附录/法代/授权/中小企业声明函/承诺书；内容级：附表1 组织机构/每份附表8 简历表/每份附表3 业绩表）；**收敛顺序**（删空行→行距28→24→22→20→18→16→14→12→11→10.5→表格删空白行/行高≤0.6cm→内边距≤0.05cm→删分页符；禁改字号/页边距）。
- **②' 生成前格式配置校验（agent 校验，用户授权环节）**：对照内容契约/招标原文检查格式配置 8 项（文件类型覆盖/字体体系/图片插入位置/独占一面/页面参数/行距缩进/图片尺寸/占位规则），**必须按 `references/M5-格式配置校验-提示词.md` v1.0 执行，不得自由发挥**；只读不改、固定清单、固定 JSON 输出；报告写入 招标解析/检查报告_格式配置.json；**结果人工确认（C7）**，确认通过前不得执行 proj-gen。
- **③ 生成**：项目模板 = 招标原文深拷贝（内容契约）+ 通用格式配置（格式契约）+ 素材清单；**只带文字占位【】与图片占位【图片：xxx】图框**；**占位将来实际填充内容必须来自解析的招标文件 + 确认的素材清单**；图片占位只放图框无实际内容（用户可能修改/增加项目模板，具体内容商务标生成时填充）。
- **④ agent 检查（用户授权环节）**：生成后调用 agent，**必须按 `references/M5-项目模板检查-提示词.md` v2.0 执行，不得自由发挥**；固定清单 + 固定 JSON 输出；代码硬校验（文字逐字比对、分页校验）先跑，报告交叉比对；**结果人工确认（C7）**。
- **⑤ 人工修改/增加** → 审核确认 → 冻结（商务标唯一模板来源）。
- **⑥ 商务标生成**：生成前系统**再次全面读取项目模板**（唯一来源）；商务标 = 解析的招标文件 + 确认的素材清单对冻结项目模板进行填充。

### 2.3 M5 agent 校验/检查 · 固化提示词（v1.6 登记）
