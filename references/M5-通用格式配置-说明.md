# M5 通用格式配置文档（v1.1，2026-10-10 V5 定稿）

> 依据：2025/2026 年 `E:\天翼同步盘\投标文件` 下和县投标文件真实样本（用户公司 `和县\word版` 全套分文件 + 资格证明及辅助资料表 56MB + 投标单位业绩材料和奖项 20MB），结合 image_spec v2.0 素材尺寸规定（用户 2026-10-03/04/05 逐条确认）编写。
> 机读配置：`scripts/m5_project/format_config.json`。

## 一、设计原则（对应 v5 流程）

1. **内容与格式分离**：项目模板 = 招标文件投标文件格式内容**深拷贝（一字不改、一个内容不丢）**；格式 = 本通用格式配置（与内容无关，一份配置适用所有项目）。
2. **图框占位**：图片位置用**直观图框**占位——灰底描边框，框内标注「素材类型 + 尺寸（高×宽 cm）」，图框即表达图片的**大小、素材、位置**；框大小符合素材尺寸规定（image_spec）。
3. **图片占位动态生成**：图片占位数量与类型**按素材清单动态生成**（业绩图片数=该业绩素材图片数；人员图片数=该人员证书/职称/身份证/社保素材数；有竣工报告要求→生成竣工报告占位，大小同合同）。
4. **只放占位无实际内容**：图框内不嵌入实际图片（用户可能修改/增加模板；具体内容商务标生成时填充）。
5. **生成前 agent 校验配置**：根据解析的招标文件校验本配置有无冲突/需补充（固化提示词控制，结果人工确认）。

## 六、独占面收敛规则（用户确认）

收敛手段**按顺序**执行，直到可收敛为一页：
1. 删除文字空行（含段前段后 0）
2. 行距 固定28磅 → 24 → 22 → 20 → 18 → 16 → 14 → 12 → 11 → 10.5磅（逐档下调）
3. 表格删除空白行、行高≤0.6cm
4. 单元格内边距≤0.05cm
5. 删除分页符（仅限深拷贝带入的多余分页符）

**禁止**：改动字号、改动页边距。仍无法收敛 → 报待人工/agent 复核，不得擅自放宽。

## 七、与现有系统的关系

- **替代**：企业模板 docx 作为格式契约的依赖（tpl_style 提取样式）→ 改为本配置直接应用格式。
- **保留**：内容契约模式深拷贝（gen_blocks）、_sanitize_copy（清格式/示例图）、page_fit（独占页收敛）、verify_text（文字硬校验）、image_spec（素材尺寸）、ph_preview（图框占位）、素材清单动态图片占位（gen_main._dynamic_image_phs）。
- **新增**：格式配置应用器（按本 JSON 对深拷贝内容套用格式）、agent 配置校验闸门（固化提示词）。
