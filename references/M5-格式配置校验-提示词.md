# M5 格式配置校验 · 固化提示词（v1.0，2026-10-10）

> 用途：**项目模板生成前**，由 agent 校验「通用格式配置 format_config.json」与
> 解析出的招标文件投标文件格式要求是否存在冲突或缺失。结果由人工确认，
> 确认通过后才允许执行 proj-gen。
> 约束：agent 必须逐字遵循本提示词执行，**不得自由发挥、不得自行做主**。

---

## 一、任务目标

对照以下三份输入，检查通用格式配置能否正确生成本项目项目模板：
1. **通用格式配置**（format_config.json）：页面/字体/表格/图片占位/图片插入位置/文件类型/独占一面/收敛规则；
2. **内容契约**（内容契约.json）：招标文件「投标文件格式」章节的格式文件清单（文件 id、标题、块范围）；
3. **招标文件源**（招标文件_*.docx 的投标文件格式部分）：文字与结构的唯一来源（深拷贝）。

输出「通过 / 不通过 / 待补充」结论与逐项问题清单。

## 二、检查清单（逐项执行，缺一不可）

| # | 检查项 | 判定规则 |
| --- | --- | --- |
| 1 | **文件类型覆盖** | 内容契约「格式文件」清单中每个文件，格式配置「文件类型」数组是否存在对应项；缺失 → 待补充（需在配置中新增文件类型） |
| 2 | **字体体系一致** | 配置字体是否统一为仿宋体系（正文12/小节14/章22/一级16/封面22-26；用户确认无黑体）；存在黑体/其他字体 → 不通过 |
| 3 | **图片插入位置覆盖** | 招标文件投标格式中出现的图片类内容（人员简历表后证书组/业绩表后合同组/附：标注段后扫描件/标题段后证书），配置「图片插入位置」是否全部覆盖；遗漏 → 待补充 |
| 4 | **独占一面覆盖** | 招标格式中独占一面的内容（封面/开标一览表/投标函/附录/法代/授权/中小企业声明函/承诺书/简历表/业绩表），配置「独占一面」清单是否覆盖；遗漏 → 待补充 |
| 5 | **页面参数** | 纸张 A4 竖向、边距（上2.54 下2.54 左2.5 右2.5）与招标格式要求一致；冲突 → 不通过 |
| 6 | **行距/缩进** | 正文固定28磅行距、首行缩进2字符、两端对齐；收敛顺序（删空行→调行距→表格→内边距→删分页符；禁改字号/页边距）已固化；冲突 → 不通过 |
| 7 | **图片尺寸规定** | 图框占位尺寸符合 image_spec 素材尺寸规定（资质12×16/23×16、执照12×16、开户12×16、注册证/岗位23×16、职称11×16、社保15×16、荣誉11×14、身份证8×5/7.5×4.5、组织机构15cm宽）；冲突 → 不通过 |
| 8 | **占位规则** | 图片占位只放图框（无实际内容）、数量按素材清单动态、位置按插入位置表；违反 → 不通过 |

## 三、输出格式（严格 JSON，写入 检查报告_格式配置.json）

```json
{
  "指令版本": "M5-config-check-v1.0",
  "项目": "<项目名>",
  "格式配置": "<format_config.json 路径>",
  "结论": "通过 | 不通过 | 待补充",
  "检查项": [
    {
      "序号": 1,
      "检查项": "文件类型覆盖",
      "结论": "通过 | 不通过 | 待补充",
      "问题": ["<问题描述，无则空>"],
      "建议": "<修改建议（如 新增文件类型 xxx），无则空>"
    }
  ],
  "说明": "<整体说明>"
}
```

## 四、硬约束

1. **只读检查**：不得修改 format_config.json、不得修改内容契约、不得生成模板；
2. **不得自由发挥**：判定只依据三份输入与本节检查清单；超出清单的发现写入「说明」并标注「建议人工确认」，不得自行改配置；
3. **结论分级**：可明确判定 → 通过/不通过；配置缺失但可补 → 待补充（给出建议）；无法判定 → 待人工确认；
4. **结果必须人工确认**：检查报告写入 招标解析/检查报告_格式配置.json 后，由用户审阅确认；确认通过前不得执行 proj-gen。

## 五、执行入口

调用方执行 `proj-config-check --project <项目名>` 生成「检查指令.json」
（含本提示词全文 + 三份输入路径 + 输出路径），agent 读取该指令执行，
报告写入 招标解析/检查报告_格式配置.json，结果由人工确认。
