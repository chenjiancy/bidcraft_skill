## 1. 商务标制作全流程（六步 + 闸门）

```
① 解析招标文件 ──→ 投标要点 / 素材清单 / 投标文件格式契约（M4 扩展）
② 检索/指定基础模板（企业级模板库：代理机构+采购方式定位）
③ 动态生成项目模板（格式契约 + 基础模板 + 素材清单）
④ 人工审核确认（闸门）→ 标记只读+版本号 → 冻结项目模板
⑤ 生成商务标（素材→占位符映射填充，图文混排，日期=投标截止日）
⑥ 自动校验（格式 diff / 占位符清零 / 敏感词残留）+ 人工复核 → 交付
```

**法规依据**：
- 本招标文件「重要提示 2」：投标人应按招标文件中"投标文件格式"编制电子投标文件；与电子系统预设模块不一致的以招标文件为准；未按格式编制评委会有权做无效标处理。
- 《招标投标法》第二十七条：投标人应当按照招标文件的要求编制投标文件，对实质性要求和条件作出响应。
- 各地实践区分「实质性格式」（投标函/报价表/承诺书/授权书/法人证明/资格证明表等，不得删减改写）与「可自行编写」部分。

## 2. M2 模板库（本期交付）

- **目录结构**：`企业级\模板库\<招标代理机构>\{投标,采购,询比价}`（D5）。
- **模板规范**：文字占位【xxx】（保留原格式）、图片占位【图片：xxx】灰色单线边框段落（D6）；图片已剥离、无敏感信息残留。
- **登记清单**：`占位符登记清单.md` 随模板库维护——每模板占位符索引（序号/占位符/说明），供 M5 填充与 M7 检查引用（D3）。
- **已交付**（2026-10-03）：大成工程咨询有限公司\投标\ 10 模板 + 登记清单；全部通过「可打开 / 0 图 / 无敏感残留 / 占位符 5~177」深度校验。
- **定位**：本库模板为**基础模板**（企业级、通用、不绑定项目）；项目模板由系统基于基础模板动态生成（§4）。
- **管理形态**：台账+CLI 全套（import/list/query 等）待开发（D4），支持按代理机构/采购方式检索。

## 3. M4 扩展：投标文件格式契约（待开发）

- **解析对象**：招标文件第五章「投标文件格式」（已确认存在于和县化工园招标文件；含封面/开标一览表/投标函及附录/法人代表资格证明等）。
- **要求**：解析出投标文件**完整结构+文字，一字不改**；保留格式原文副本作人工核对基准；生成结构化契约 JSON。
- **分级**（D9）：实质性格式（投标函、报价表、承诺书、授权委托书、法定代表人身份证明、资格证明及辅助资料表等——不得删减改写）／参考格式（可自行编写部分）。
- **契约字段**：文件清单（顺序/份数/装订/签章要求）、每文件结构约束（表格行列数、表头文字、条款原文、字体字号页码、必填项、图片要求）。
- **落位**：项目级 `<企业>\项目级\<项目名>\招标解析\格式契约\`（契约 JSON + 原文副本 + 人读摘要）。

## 4. 动态生成项目模板（D10，M5 前置阶段）

- **输入**：格式契约（M4 扩展）+ 基础模板（M2）+ 素材清单（M4）。
- **动态语义 1（文字）**：解析出的投标文件格式与基础模板存在**非占位文字差异**时，以**解析出的格式文字为准**动态更新（招标文件文字不能有任何改变）。
- **动态语义 2（素材）**：素材占位按**素材清单动态生成**——证书可能只有一页或多页、人员配备行数/简历表份数/业绩份数随清单增减，占位符数量与表格行数动态调整，不硬套基础模板的固定占位。
- **落位**：项目级 `<企业>\项目级\<项目名>\项目模板\`（项目模板 + 项目占位符清单）。
- **输出**：可人工编辑的 docx 项目模板（含占位符）。

## 5. 项目模板生命周期与冻结（D11）

```
生成（动态）→ 人工修改 → 审核确认 → 标记只读+版本号 → 冻结
                                     ↑（防止后续误改）
生成商务标只认冻结版项目模板
```

- 冻结标记落于项目模板目录元数据（只读属性 + 版本号 + 审核人/日期），变更须走解冻流程。

## 6. 商务标生成（M5）与校验（M7）

- **素材映射**（D12）：素材清单 JSON 增加「用途/占位符键」字段，生成时自动填图（图片按占位尺寸缩放/裁切）；未匹配占位符进人工补录清单。
- **日期**：商务标所有日期统一引用项目参数表（投标截止日期/开标日期），避免各处日期不一致。
- **校验三道**（D13）：
  1. 格式 diff：生成稿与格式契约逐表头/逐条款对比；
  2. 占位符清零：无【】残留；
  3. 敏感词/旧数据残留扫描（已在本期模板制作中验证可行）。
- **人工复核不可少**：机器校验通过后仍须人工复核，人工为最终闸门。
