# 一、监理工作依据
1. 国家和地方有关工程建设的法律、法规与规章；
2. 《建设工程监理规范》GB/T 50319-2013；
3. 本项目招标文件、监理合同及施工合同；
4. 施工图设计文件与现行工程建设标准、规范。
## （一）监理工作目标
确保工程质量达到一次性验收合格标准，争创省级优质工程；进度满足合同节点要求；投资控制在批准概算内；杜绝重大安全事故。
| 目标项 | 目标要求 |
| --- | --- |
| 质量 | 一次验收合格率 100%，争创省级优质工程 |
| 进度 | 满足合同工期及各里程碑节点 |
| 投资 | 控制在批准概算范围内 |
| 安全 | 无重大安全责任事故 |
### 1. 监理工作制度
建立监理例会制度、旁站监理制度、见证取样制度、巡视检查制度、资料管理制度。
#### （1）例会制度
每周召开监理例会，形成会议纪要并闭环跟踪落实。
