四 · 生成链路消费（T10 导出）

S5 章节树落盘 → S6 docx 导出逐组取用 tech-outline / tech-export

scripts/m6_tech/export.py：_row_of("palette"|"font"|"headingSystem"|"tocStyle"|"tableStyle"|"captionSystem"|"decoration"|"imageLayout") + cfg.get("cover"/"pageSetup"/"paragraphStyle"/"headerFooter"/"preset")
导出引擎以章节树 layout 十五组 为唯一排版配置：palette 五色（primary/accent/heading/tableFill/coverBg）→ 封面 SVG 与标题色；cover → 封面版式；decoration → 标题装饰；font → 字体方案；pageSetup → 页面/边距；headingSystem → 标题编号；tocStyle → 目录；tableStyle → 表格边框/底纹；captionSystem → 表题图题编号；paragraphStyle → 行距；headerFooter → 页眉页脚/页码；imageLayout → 图排；preset → 正文版式。产出 技术标_<项目>.docx。
