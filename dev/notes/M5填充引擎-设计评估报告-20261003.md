# M5 填充引擎 v1.0 设计评估报告

> 日期：2026-10-03 ｜ 状态：**待用户确认** ｜ 前置已确认：图片尺寸口径（A4 竖向/高×宽/宽≤16/同页上下排）

## 一、目标与范围

读取**冻结的项目模板**（10 个 docx）+ **素材清单.json** + **企业级素材库**，生成**商务标**（图文混排 docx）：
投标函/投标函附录/开标一览表/封面/法定代表人身份证明/授权委托书/资格证明及辅助资料表/承诺函×2/中小企业声明函。
**占位符清零**（除待办素材按缺图机制处理），**落款留空**（范本要求手签），**日期 = 投标截止日期（2026-10-09）**。

## 二、输入数据源（已探查确认）

| 数据 | 位置 | 关键内容 |
|---|---|---|
| 项目模板（冻结版） | `项目级\...\项目模板\`（10 docx） | 占位符【xxx】+ 表格结构 |
| 素材清单 | `招标解析\素材清单.json` | 项目名/编号、招标代理机构、监理人员配置口径、qualification/iso/honors（含图片 path）、personnel、图片尺寸口径 |
| 投标截止日期 | `招标解析\投标要点.json → deadline` | **2026-10-09 09:00** |
| 图片素材库 | `企业级\素材库\`（资质/荣誉/人员/业绩/财务/企业介绍） | 图片 path 相对此根 |

## 三、填充规则设计

### 1. 文字占位（段落/表格单元格）
- KEY_MAP 占位键 → 素材清单字段：【项目名称】【项目编号】【投标人名称】【日期】等；
- **【日期】= 投标截止日期（2026-10-09）**；
- 落款【投标人名称】【签字或盖章】**留空不填**（范本要求）；
- 中小企业声明函：默认示例值（SME_SAMPLE：62/493.43/134.59/小型企业，可改）+ 日期；
- 承诺函（总监到岗/开户许可证）：【项目名称】【项目编号】+ 日期 + 投标人名称。

### 2. 图片占位（17 类，按已确认口径）
- 从素材库按 path 取图 → 按「高×宽」框等比插入 → 删除原【图片：xxx】占位段；
- 同页多图上下排；职称证/证书类按人员分组、组内排完另起一页；身份证与正文同页不得跨页；
- 组织机构框图：素材库 `企业介绍\组织机构图_20261001.png`（表内全宽 15cm）。

### 3. 表格填充
| 表 | 内容 | 处理 |
|---|---|---|
| 附表6 监理人员资质表（表格6） | 序号/姓名/年龄/学历/专业/职称/项目职务/监理时段/备注 | 按 personnel 6 人逐行填 |
| 附表7 配备表 | 人员 6 行 | 按监理人员配置口径 |
| 附表8 简历表 ×6 | 姓名/性别/出生年月/学历/院校/政治面貌/职称/工作年限/身份证号/证书/经历 | **方式待确认（Q1）** |
| 附表9 仪器设备表 | 20 行固定数据 | 已内嵌模板，不动 |
| 荣誉/业绩 | — | **呈现待确认（Q2/Q3）** |

### 4. 输出
- 输出目录：`项目级\...\商务标\`（10 docx 同名）；
- 伴随产物：`生成记录.json`（各文件占位填充数/缺图清单/未生成项）、`缺图清单.md`（待办素材）。

## 四、验证方案

1. **占位符清零检查**：商务标 10 文件中无【xxx】残留（除缺图机制豁免项）——自动化断言；
2. **日期断言**：所有【日期】处 = 2026-10-09；
3. **回归**：现有 185 测试基线全绿；新增填充引擎测试；
4. **抽样对比**：商务标 vs 项目模板范本逐文件 diff（文字 100% 契约保留、仅占位被替换）。

## 五、待用户确认（3 项）

- **Q1 简历表方式**：A 填文字（需补齐 17 字段/人）；B 贴简历扫描件（素材库 `人员\<姓名>\简历_xxx.png`，按尺寸口径）；C 文字+扫描件。
- **Q2 缺图素材处理**：A 跳过占位+生成缺图清单（商务标干净）；B 保留占位段待后补。
- **Q3 业绩材料呈现**：评标 8 分（6000 万+市政业绩 2 项）——A 业绩表行+合同扫描件；B 仅合同扫描件图片；放置位置（资格证明内/独立文件）待定。

## 六、分阶段

- **v1.0**：文字+日期+已就绪图片（资质/ISO/荣誉/开户许可证/身份证/组织机构图/人员证书）；
- **v1.1**：简历表（按 Q1 确认方式）+ 业绩材料（按 Q3）；
- 监理大纲（暗标 50 分）不在商务标范围，另行模块。
