## 二、偏离项（必须停下确认）

### D-1【必须授权】技术标 agent 写作不在 §7.4 授权列表内

- **规则原文**（SKILL.md §7.4）：“商务标制作 = 高可靠性系统工程，整个过程必须使用代码……**AI/agent 仅在用户明确授权的环节使用**：招标文件解析（双通道）、标书检查/模拟评标等后续环节；**未授权不得擅自使用 agent、不得自行做主**。”
- **现状**：该授权列表写于 M6 立项前，未包含“技术标制作”。而 M6 的既定形态（需求对齐 v1.0 §1.2、契约 §1.3、提示词 v1.0）是 **agent 写正文**（P2/P3/P5），脚本只做校验与落盘。
- **判断**：用户在 D3/D6 裁决中已实质性选择“agent 整章生成 + 精修”，但按 §7.4 的文字，仍缺一条**明确授权条目**。
- **我的方案**：请用户确认后，在 `references/固化提示词.md` 增补一条（v1.x）：“M6 技术标制作的**正文生成/目录编制/精修**授权 agent + 固化提示词（P2/P3/P5）执行；结构校验、覆盖判定、篇幅核算、敏感扫描、状态机、合并导出必须由确定性脚本完成；每个闸门须人工确认。”
- **一致性**：⚠️ **偏离**——未确认前不得实现任何 agent 调用（T3 纯逻辑层本身不含 agent 调用，可先做；但 T4/T5 前必须落地此授权）。

### D-2【文档滞后】SKILL.md M6 行仍为“按模板/评分项生成技术方案”

- **规则原文**（SKILL.md 第 85 行）：`| M6 | 技术标制作 | 按模板/评分项生成技术方案 | ⏳ 待实现 |`
